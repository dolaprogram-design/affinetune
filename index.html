🏆 ตารางประเมินคะแนนคุณภาพรวมและคัดกรองข้อบกพร่องอัตโนมัติ

คำนวณคะแนนถ่วงน้ำหนัก: Focus & Sharpness (50%) + Contrast & Exposure (30%) + Technical Stability (20%)

ไฟล์ภาพ & อุปกรณ์ คะแนนรวม & เกรด คะแนนแยก 3 มิติ (Sub-Indices) ผลการวินิจฉัยและข้อสังเกตทางเทคนิค
ยังไม่มีข้อมูล กรุณาอัปโหลดไฟล์ภาพด้านบนเพื่อประเมินเกรดคุณภาพ

📐 วิเคราะห์โครงสร้างเส้นขอบ (Canny Edge Map) และการกระจายแสง (RGB Histogram)

ตรวจสอบรายละเอียดพื้นผิวบริเวณจุดโฟกัส (ROI ความละเอียดสูง 560×560px) พร้อมกราฟการกระจายแสง 3 ช่องสี

ยังไม่มีข้อมูล กรุณาอัปโหลดไฟล์ภาพเพื่อแสดงผล Edge Map และ RGB Histogram
ยังไม่มีข้อมูล กรุณาอัปโหลดไฟล์ภาพเพื่อแสดงกราฟวิเคราะห์สถิติและอภิข้อมูล MakerNotes เชิงลึก

🔬 เปรียบเทียบความคมชัดรายภาพ (AF Sharpness vs Peak Sharpness)

เปรียบเทียบค่า Laplacian Variance ณ จุดโฟกัสกล้องกับจุดที่คมชัดที่สุดในเฟรม

📊 ค่าเฉลี่ยความคมชัดและคะแนนคุณภาพจำแนกตามกลุ่ม ISO

จัดกลุ่มตามค่าความไวแสง (ISO Group Analysis)

📈 ความสัมพันธ์ระหว่าง Edge Density (%) กับ AF Sharpness

ช่วยแยกแยะภาพที่มีรายละเอียดเส้นขอบคมชัดจริง ออกจากภาพที่ Sharpness สูงเพราะ Grain/Noise

📋 ตารางสรุปสถิติจัดกลุ่มตามค่า ISO (ISO Group Summary)

ค่าเฉลี่ยความคมชัด คะแนนคุณภาพ และจำนวนภาพในแต่ละช่วง ISO

กลุ่ม ISO จำนวนภาพ เฉลี่ย AF Sharpness เฉลี่ย Edge Density เฉลี่ย Quality Score

🗂️ ตารางอภิข้อมูลเชิงลึกจาก MakerNotes (Deep RAW/EXIF Metadata)

🔌 REST API Endpoint & โครงสร้างข้อมูล JSON สำหรับเชื่อมต่อระบบอื่น

สามารถส่งไฟล์ภาพเข้าสู่ Endpoint POST /api/v1/quality-evaluate เพื่อรับผลประเมินคุณภาพแบบ JSON ได้ทันที

ตัวอย่างการเรียกใช้งานด้วย Python (requests)
import requests

url = "http://localhost:8000/api/v1/quality-evaluate"
with open("sample_photo.NEF", "rb") as f:
    res = requests.post(url, files={"file": f})

data = res.json()
print("Grade:", data["quality_evaluation"]["grade_label"])
print("Score:", data["quality_evaluation"]["quality_score"])
print("Issues:", data["quality_evaluation"]["issues_detected"])
ผลลัพธ์ JSON จริงของไฟล์ล่าสุดในระบบ
